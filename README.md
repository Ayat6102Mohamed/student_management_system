Student Management System (PHP & MySQL)

Student Management System is a simple web application built using PHP (Procedural) and MySQL. It demonstrates the basic CRUD (Create, Read, Update, Delete) operations without using any framework or Object-Oriented Programming (OOP).

The application allows users to:
  View all students.
  Add a new student.
  Edit existing student information.
  Delete student records.
  Store and retrieve data from a MySQL database.
Technologies Used :
  PHP (Procedural)
  MySQL
  MySQLi
  HTML
Learning Objectives :
This project helps beginners understand:

  PHP file organization
  Database connection using MySQLi
  Handling GET and POST requests
  CRUD operations
  HTML forms
  Data retrieval and display
  Page redirection with header()
